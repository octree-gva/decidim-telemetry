# Documentation website

[Docusaurus 3](https://docusaurus.io/) site with docs at the site root (`routeBasePath: /`). Published at [octree.ch/decidim-telemetry](https://octree.ch/decidim-telemetry/).

## Site layout

```text
website/docs/
  index.md           # Overview (sysadmin entry)
  install.md         # Installation
  configuration.md   # Env vars
  endpoints.md       # Health + metrics URLs
  prometheus.md        # Scrape jobs
  metrics.md         # Counter reference
  security.md        # Auth and exposure
  faq.md             # Troubleshooting
  developer/         # Contributors
```

Sidebar is autogenerated from the folder tree (`sidebars.ts`).

## Edit locally

```bash
cd website
yarn
yarn start
```

## Build before merge

```bash
cd website && yarn build
```

`onBrokenLinks: 'throw'` — fix broken links before merging.
